# Telegram Multimodal Studio

[![Python 3.11+](https://img.shields.io/badge/python-3.11%20%7C%203.12-blue.svg)](https://www.python.org/)
[![aiogram 3.15+](https://img.shields.io/badge/aiogram-3.15+-0088cc.svg)](https://docs.aiogram.dev/)
[![NormaHub Gateway](https://img.shields.io/badge/gateway-NormaHub%20v1-green.svg)](https://normahub.cc)
[![Ruff](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/astral-sh/ruff/main/assets/badge/v2.json)](https://github.com/astral-sh/ruff)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Production-ready Telegram-бот на **aiogram 3.15+** для мультимодальной работы с нейросетями: транскрипция голосовых сообщений и **видео-кружочков** через **Whisper-1**, а также генерация видео через **ByteDance SeeDance 2.5** и **xAI Grok Imagine Video** через шлюз [NormaHub](https://normahub.cc).

Прямой доступ из России и СНГ без VPN, оплата в рублях (СБП, карты МИР, безналичный расчет с НДС 20% по ЭДО Диадок).

---

## Ключевые возможности

- 🎙️ **Расшифровка голосовых и кружочков**: Бот принимает `.oga`/`.ogg` (голосовые) и `.mp4` (видео-кружочки Telegram), отправляя их напрямую в шлюз Whisper-1 без локальной перекодировки.
- 🎬 **Генерация видео SeeDance 2.5 & Grok**: Поддержка Text-to-Video (T2V) и Image-to-Video (I2V) в разрешениях 1080p с выбором соотношения сторон (`16:9`, `9:16`, `1:1`).
- 🔄 **Очередь задач на SQLite WAL с защитой от сбоев**: Видеогенерация длится 1–3 минуты. Все активные задачи сохраняются в SQLite с журналом Write-Ahead Logging (`WAL`). При перезапуске или обновлении бота задачи не теряются: воркер подхватывает генерации и доставляет готовые видео пользователям.
- 📊 **Интерактивный прогресс-бар**: Telegram-сообщение обновляется в реальном времени (`[██████░░░░] 60%`) с описанием текущего этапа рендера и таймером, учитывая ограничения Telegram FloodWait (дебаунсинг правок).
- ⚡ **Действия в 1 клик**: После распознавания аудио бот предлагает сразу сгенерировать видео по сценарию из сказанного текста.

## Быстрый старт

### 1. Клонирование и настройка окружения

```bash
git clone https://github.com/normahubcc/telegram-multimodal-studio.git
cd telegram-multimodal-studio

# Копируем шаблон переменных окружения
cp .env.example .env
```

Отредактируйте `.env`:
```env
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
NORMAHUB_API_KEY=nr_hub_ваш_ключ_из_normahub_cc
NORMAHUB_BASE_URL=https://api.normahub.cc/v1
```

> 🔑 Получить API-ключ можно в личном кабинете [normahub.cc](https://normahub.cc). Пополнение доступно через СБП, карты МИР и корпоративный счет с НДС 20%.

### 2. Запуск локально

```bash
# Создание виртуального окружения
python3 -m venv .venv
source .venv/bin/activate

# Установка зависимостей
pip install -e ".[dev]"

# Запуск бота
python -m bot.main
```

### 3. Запуск через Docker Compose

```bash
docker compose up -d --build
```

База данных очереди задач автоматически сохраняется в изолированном томе `telegram-multimodal-studio-data`.

## Команды и использование

| Команда | Описание |
| :--- | :--- |
| `/start` | Главное интерактивное меню студии |
| `/help` | Полное руководство пользователя и примеры флагов |
| `/models` | Каталог поддерживаемых моделей и их спецификации |
| `/balance` | Проверка статуса подключения к NormaHub и баланса |
| `/video <промпт>` | Генерация видео моделью по умолчанию (`seedance-2.5`) |
| `/seedance <промпт>` | Принудительная генерация через **ByteDance SeeDance 2.5** |
| `/grok <промпт>` | Принудительная генерация через **xAI Grok Imagine Video 1.5** |

### Примеры параметров видео:
```text
/video Неоновый киберпанк-самурай идет по дождливому городу, 4k cinematic --ratio 16:9
/seedance Спортивный автомобиль на горном серпантине на закате --ratio 9:16 --duration 10
/grok Сюрреалистичный сон с парящими кристаллами в космосе --ratio 1:1
```

### Режим Image-to-Video (оживление картинок):
1. Отправьте фотографию в чат.
2. В подписи к фото укажите `/video Оживи это изображение: плавный ветер и солнечные блики`.
3. Или ответьте командой `/video ...` на любое ранее отправленное изображение.

## Часто задаваемые вопросы (FAQ)

### 1. Как бот транскрибирует кружочки Telegram без сторонних конвертеров?
Кружочки в Telegram приходят как объекты `VideoNote` в формате MPEG-4 (`.mp4`). Шлюз NormaHub Whisper (`/v1/audio/transcriptions`) аппаратно принимает медиа-потоки в форматах `.mp4`, `.m4a`, `.oga`, `.ogg`, `.mp3` и `.wav` размером до 25 МБ. Бот скачивает бинарный поток через Telegram Bot API и передает его в NormaHub в `multipart/form-data`, экономя процессорное время сервера на локальной переконвертации.

### 2. Что произойдет, если сервер перезагрузится во время генерации видео?
Благодаря архитектуре `TaskQueue` на базе SQLite с включенным режимом Write-Ahead Logging (`WAL`):
1. Все метаданные задачи (ID чата, ID служебного сообщения с прогресс-баром, промпт и upstream ID на NormaHub) зафиксированы на диске.
2. При рестарте бота `QueueWorker` запрашивает незавершенные задачи со статусами `pending`, `submitting` и `processing`.
3. Воркер автоматически возобновляет поллинг состояния задачи на шлюзе NormaHub.
4. После завершения рендера готовое видео автоматически отправляется пользователю в исходный диалог.

### 3. Как бот не ловит ошибку Telegram `FloodWait` при обновлении прогресс-бара?
Telegram накладывает жесткие лимиты на частоту вызова метода `editMessageText`. `QueueWorker` регулирует частоту обновления интерфейса: сообщение редактируется не чаще одного раза в 4 секунды, либо при резком изменении прогресса (>= 15%). При возникновении временной ошибки Telegram воркер не прерывает задачу, а продолжает опрос нейросети.

### 4. Нужен ли VPN для работы в РФ?
Нет. Шлюз `https://api.normahub.cc/v1` оптимизирован для прямого маршрутизированного доступа из России и стран СНГ. Вызовы к ByteDance SeeDance, OpenAI Whisper и xAI Grok выполняются через инфраструктуру NormaHub с минимальным сетевым пингом.

### 5. Как юридическим лицам оплачивать генерации?
NormaHub поддерживает безналичную оплату по расчетному счету для российских юридических лиц и ИП с закрывающими документами (УПД с НДС 20%) через систему электронного документооборота (ЭДО Диадок). Для физических лиц доступна моментальная оплата через СБП и карты МИР.
